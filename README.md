# Blinkit-Sales-Analysis
This Blinkit Sales Analysis Dashboard was developed in Tableau to analyze sales performance and customer purchasing trends across different food product categories. 
The dashboard includes interactive filters for outlet location and product fat content (Regular and Low Fat), enabling detailed category-wise analysis.
Dynamic charts, timelines, and visual insights were designed to track sales trends, product demand, and outlet performance effectively.
The project provides valuable business insights that support inventory planning, customer preference analysis, and data-driven decision-making.
